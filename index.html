Fantasy AI Assistant

A private, non-commercial assistant designed to help one fantasy football manager understand Yahoo Fantasy Sports data and make better-informed weekly lineup and waiver decisions.

Read-only integrationSingle-user use caseNo public fantasy data service

Purpose

Bring authorized Yahoo Fantasy Football league data into a private AI analysis workflow using a custom Model Context Protocol (MCP) service connected to ChatGPT.

The assistant will generate recommendations; the manager retains full control of roster transactions.

Intended audience

One individual user managing a personal team in a 12-team Yahoo Fantasy Football league.

Not intended for commercial use, public access, redistribution, or resale of Yahoo data.

Yahoo Fantasy Sports data requested

  • League settings, scoring rules, standings, and team information
  • Authorized team rosters, starters, and bench players
  • Weekly matchups, fantasy scores, and available projections
  • Player statistics, eligibility, and injury information where available
  • Available free agents, waiver status, and relevant transaction history

Planned technical design

Yahoo OAuth 2.0 authorization → private HTTPS application service → read-only MCP tools → ChatGPT.

API access and exact implementation details are subject to Yahoo approval and applicable platform capabilities.

Security and privacy

OAuth credentials and tokens will be held in secure server-side storage, never in this public page or source repository.

Access will be restricted to the authorized account. No Yahoo write operations are requested.
